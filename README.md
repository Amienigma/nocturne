# NOCTURNE

A dark-music sound lab in a single HTML file. It has a synth keyboard, a trap drum pad, genre sound banks and a 12-track step sequencer. Every sound is synthesized live with the Web Audio API, so it uses no samples.

**Live:** see the repo homepage link.

## Features
- 808 and bass voices on a playable C2–C4 keyboard
- Trap drums (kicks, snares, claps, hats), with Q–I keyboard shortcuts, hat rolls and velocity and randomization controls
- Sound banks: Memphis horrorcore, coldwave/darkwave, dark house, DSBM atmosphere, abstract vocal textures, and looping ambience (rain, wind, vinyl and more)
- A 12-track step sequencer with 8, 16 or 32 steps, swing, mute/solo, randomize, presets, and right-click to raise a step's velocity
- A master limiter, CRT look and **REC** button, which exports your session as a `.webm` audio file

## Run
Open `index.html` in any modern browser, or serve the folder statically. It has no build step, needs no API key and works offline (apart from Google Fonts). Click once to start audio.
